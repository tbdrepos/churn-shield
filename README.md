# Churn Shield

https://churn-shield-lyart.vercel.app/

Churn Shield is a full-stack machine learning platform for customer churn prediction and analysis.

Built with **FastAPI**, **scikit-learn**, and **Vue 3**, it enables users to upload datasets, train multiple churn prediction models, generate explainable predictions, and explore data through interactive dashboards.

## Features

- 📊 Dataset upload and validation
- 🤖 Train and compare multiple ML models
- 🔮 Real-time churn prediction
- 🧠 SHAP-powered feature impact explanations
- 📈 Data and model insights dashboards
- 🎨 Dynamic chart rendering with ApexCharts
- ⚙️ User-configurable model and threshold settings
- 🔒 Secure authentication and account management

## Tech Stack

### Backend
- FastAPI
- Pydantic
- Sqlmodel
- scikit-learn
- SHAP

### Frontend
- Vue 3
- TypeScript
- Pinia
- ApexCharts

## Goal

Churn Shield helps businesses identify customers at risk of leaving, understand the factors driving churn, and make data-driven retention decisions through transparent and explainable machine learning.
